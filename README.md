# Веб-сервис извлечения данных из документов

ВКР: «Разработка веб-сервиса автоматизированного извлечения данных из документов с применением методов обработки естественного языка».

Сервис по настраиваемым шаблонам извлекает структурированные данные из документов (PDF, DOCX, сканы) гибридным методом: правила (regex) + NER, недостающие поля — через LLM.

## Стек
- Веб-приложение: PHP 8, Laravel, Livewire
- Сервис обработки: Python, FastAPI (PyMuPDF, python-docx, Tesseract, Natasha), локальная LLM через Ollama
- Хранение и очередь: PostgreSQL (очередь задач — в базе)
- Развёртывание: Docker Compose

## Запуск в Docker (любой компьютер с Windows)

Нужен только Docker Desktop — PHP, PostgreSQL, Python и Tesseract ставятся внутри контейнеров. Рекомендуется 8 ГБ оперативной памяти и 15 ГБ свободного места.

1. **WSL 2** (подсистема Linux, нужна Docker Desktop). PowerShell **от имени администратора**: `wsl --install`, затем перезагрузить компьютер. Если Windows сообщит, что выключена виртуализация, — включить её в BIOS (Intel VT-x / AMD-V; на офисных ноутбуках обычно уже включена).
2. **Docker Desktop**: https://www.docker.com/products/docker-desktop/ → установить, запустить и дождаться внизу окна «Engine running».
3. **Проект**: на GitHub → Code → Download ZIP (или `git clone`), распаковать, например, в `C:\docextract`.
4. **Запуск**: двойной щелчок по `start.bat`. Первый раз — 10–20 минут: скачиваются образы и библиотеки, собирается интерфейс. Скрипт сам создаёт `.env` со случайными паролями, ждёт готовности и открывает http://localhost:8000.
5. **Регистрация и администратор**: зарегистрироваться на сайте (в Docker сайт работает в боевом режиме: пароль не короче 12 символов, строчные и заглавные буквы, цифра и символ), затем в папке проекта:

```
docker compose exec web php artisan app:create-admin --email=ваш@e-mail
```

- **Остановить** — `stop.bat`; база и документы сохраняются, следующий запуск — снова `start.bat` (уже за минуту).
- **Обновить** после изменений в коде — `start.bat` пересоберёт образы.
- **Начать с чистой базы** — `docker compose down -v` (удаляет все данные!).
- **Логи** — `docker compose logs -f web queue processor`.
- **Локальная LLM** по умолчанию выключена: на ноутбуке без видеокарты она отвечает 20–60 с на документ. Включить: в `.env` поставить `LLM_ENABLED=true` и запустить `start.bat` — скачается модель `qwen2.5:3b` (~2 ГБ); на компьютере с видеокартой NVIDIA лучше `LLM_MODEL=qwen2.5:7b`. Документ при этом не покидает компьютер.
- Сайт открыт только на этом компьютере (`127.0.0.1`), база, сервис обработки и LLM наружу не открыты вовсе.

Для разработки без Docker — `web/README.md` и `processor/README.md`.

## Структура репозитория
- `ПТП (2).docx` — паспорт проекта
- `bpmn_as_is.bpmn`, `bpmn_to_be.bpmn` — BPMN-модели процесса
- `схемы/` — IDEF0, UML, архитектура, роли, схема БД, алгоритм (draw.io)
- `processor/` — сервис обработки документов (Python, FastAPI): извлечение текста и OCR, правила, NER, LLM, оценка качества
- `web/` — веб-приложение (Laravel, Livewire): пользователи и роли, шаблоны, документы, результаты
